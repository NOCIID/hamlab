# Experiments

Checks, batches and summaries for the solvers in [hamlab](../README.md). Run everything from
the repository root. Batch scripts (`run_*.sh`) use the interpreter in `PY` (default `python`), e.g.
`PY=python caffeinate -i bash experiments/gpdp/run_report_config.sh`.

Trained runs are written to `runs/endogenous/<solver>/<run name>/` and are not versioned: a fresh
copy of the repository has none. The logs of each batch and the tables it produced are versioned in
each folder's `results/`, so the published numbers can be read without training anything.

## Checks that need no saved runs

| Script | What it checks |
|---|---|
| `models/check_krusell_smith.py` | hamlab's Krusell-Smith model against MFAX's environment, exact equality (part 4 uses saved agents and skips those not trained yet) |
| `models/check_huggett.py` | hamlab's Huggett model against the SRL tutorial code, exact equality (reference outputs in `models/data/`, regenerated by `make_huggett_reference.py`) |
| `gp_critic/check_equivalence.py` | with the GP critic switched off, the GP-critic train step reproduces MFAX's SPG / RSPG train step exactly |
| `deepham/deepham_checks.py` | DeepHAM: the window objective against the exact value, fictitious play (no gradient through the others' behaviour), the evaluation wrapper against MFAX's simulation |

## Batches: which runs they create, and what they need

| Batch | Creates (under `runs/endogenous/`) | Needs first |
|---|---|---|
| `gp_critic/run_all.sh` | `hsm_rspg_gp/` and `hsm_spg_gp/`: `base_s*` (MFAX's RSPG / SPG), `gp_s*`, `gpfix_s*`, ... (about 9 hours; every number of [SUMMARY.md](gp_critic/SUMMARY.md)) | nothing |
| `gp_critic/run_gp62.sh` | `hsm_rspg_gp/gp62_s*`, `hsm_spg_gp/gp62_s*` | `run_all.sh` |
| `gpdp/run_report_config.sh` | `gpdp/report_singlevgp_a1_s*`: the reference GPDP configuration, the baseline of the other GPDP batches | nothing |
| `gpdp/run_step4.sh` | `gpdp/const15_a05_s*`, `gpdp/const15_a1_s0` | `gp_critic/run_all.sh` (for the RSPG baselines in the evaluation) |
| `gpdp/run_check1_grid.sh` | `gpdp/grid_*` (GPDP on MFAX's grid actions) | `run_step4.sh`, `gp_critic/run_all.sh` |
| `gpdp/run_check_single_vgp.sh` | `gpdp/singlevgp_const15_a05_s*` (one value GP for all periods) | `run_step4.sh` |
| `gpdp/run_check_time.sh` | `gpdp/notime_const15_a05_s*` (policy GP without the date) | `run_step4.sh` |
| `gpdp/run_check_memory.sh` | `hsm_rspg_gp/gpfix_h8_s*` (RSPG with an 8-dim GRU) and `gpdp/memory_h8_s*` | nothing |
| `gpdp/run_check_memory_h.sh` | `gpdp/memory_h8_only_s*` (policy GP on the GRU state only) | `run_check_memory.sh` |
| `gpdp/run_lom.sh` | `gpdp/lom_s*`, `gpdp/lom_paths8_s*` (GP law of motion) | nothing |
| `gpdp/run_memory_learn.sh` | `gpdp/memlearn_<TAG>_*` (policy GP with a learned memory) | nothing |
| `gpdp/run_jepa_lom.sh` | `gpdp/jepalom_d16_s*` (law of motion from the JEPA world model) | the encoder: `python experiments/gpdp/jepa_wm_pretrain.py --d 16 --name d16` |
| `deepham/run_deepham.sh` | `deepham/deepham_gm1_s*` | nothing |

Every GPDP and DeepHAM batch ends with the held-out evaluation of its runs (`gpdp/step4_evaluate.py`:
MFAX's exploitability) and their consumption-equivalent relative errors (`gpdp/relative_errors.py`).
The GP-critic batches compare their runs with `gp_critic/compare_runs.py` and `summarize_seeds.py`.

## Scripts that read saved runs

| Script | Runs it reads (by default; see its options) | Created by |

| `gpdp/step1_continuous_br.py`, `step2_backward_pass.py`, `step3_policy_gp.py` | `hsm_rspg_gp/gpfix_s0` | `gp_critic/run_all.sh` |

| `gp_critic/check_*.py`, `compare_runs.py`, `summarize_seeds.py` | given on the command line | `gp_critic/run_all.sh` |
